# The Dawnworks — производственная разбивка v4 (утверждённая)

Этот документ — **единственный источник правды** по таймингу и механике. Он заменяет тайминги `02_treatment_v3.md` (96 с) и уточняет §7 библии. Хронометраж — **100,0 с = 2400 кадров @ 24 fps**.

## 1. Механика храповика (ответ на замечания 3-го раунда критики)

Проблема v3: было непонятно, *почему* Хоб держит ручку руками и *когда* механизм становится безопасным. Решение v4 — одна наглядная причинная схема:

1. Лебёдка: ручка → шестерня-трибка (12 зубьев) → большое колесо (36 зубьев) на валу барабана → трос → стрела крана → фонарь-солнце. Всё управляется одним скаляром `theta` (угол ручки).
2. На валу барабана — **храповое колесо** с крупными пилообразными зубьями. Над ним на оси висит тяжёлая латунная **собачка**. Обычно собачка лежит во впадине между зубьями и не даёт солнцу провернуть механизм назад.
3. Птица свила гнездо **прямо во впадине храповика под зубом собачки**. Поэтому:
   - собачка не может упасть во впадину → механизм не застопорен → вес солнца тянет ручку назад → **Хоб держит ручку мышцами**;
   - если повернуть ручку (вперёд или назад), колесо повернётся и **зуб собачки раздавит гнездо**;
   - Хоб не может достать гнездо сам: обе руки нужны, чтобы держать ручку, а его пальцы больше щели кожуха.
4. Рывок Рен (S05) поворачивает колесо на миллиметры — кончик собачки опускается к яйцу. Хоб перехватывает ручку.
5. Рен (маленькие руки — её сила) достаёт гнездо. Собачка падает во впадину: **КЛАЦ**.
6. **Доказательство безопасности (обязательный кадр):** Хоб медленно разжимает пальцы, ручка остаётся на месте, собачка сидит в зубе, солнце не падает. Только после этого плечи опускаются и пар выходит долгим выдохом.
7. При совместном подъёме собачка прыгает по зубьям: каждый щелчок — восьмая нота темпа 96 BPM.

### Общие правила для ассетов
- ES-модули, `import * as THREE from 'three'`, хелперы из `src/core/*`. Единицы — сантиметры, Y вверх, персонажи смотрят в +Z, ноги на y = 0.
- Материалы — `MeshStandardMaterial`/`MeshPhysicalMaterial` (без transmission) или свои шейдеры. **Не задавать `envMap`** — окружение даёт `scene.environment` набора.
- Всё детерминировано: `set(state)` — чистая функция состояния; случайность только через `rng(seed)`.
- Текстуры ≤ 1024², генерируются один раз при загрузке. Без внешних изображений, шрифтов из сети, моделей.
- Бюджет SwiftShader: ассет персонажа ≤ 120k треугольников; в наборе ≤ 3 источника света с тенями.

## 5. Производственные упрощения (честно)
- Сокращено против библии: господин с часами и кот — только в фоне S01/S08b; бумажные птицы — небольшая стайка; рукав Рен не закатывается.
- Диалогов и голосов нет; смешок Рен передаётся мимикой и плечами, без голоса.
